# Driving License Reminder App

A cross-platform mobile and web application that helps users track driving license and road tax expiry dates.

## Features
- User authentication (Firebase)
- License and vehicle management
- Expiry tracking system (30-day logic)
- Reminder alerts

## Technologies
- React Native (Expo)
- React Native Web
- Firebase Authentication
- Firestore Database

## Platforms
- Mobile (Android & iOS)
- Web (via Expo)
